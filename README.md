# Programmed Minds | العقول المبرمجة

ثمانية وكلاء يحوّلون وصف مشروع أو شروط مسابقة إلى بحث موثق، وفكرة محسّنة، وخطة تنفيذ وتوجيه تصميم. وبعد تنفيذ المشروع، يراجع المختبر نتائج أدوات الفحص الأصلية. يعمل التطبيق محليًا، ويحفظ التقارير ويعرضها بواجهة عربية.

هذا تنفيذ قابل للتشغيل، وليس ملف تلقينات فقط. لكنه **لا يكتب مشروعك المستهدف تلقائيًا**: يخرج ملف `HANDOFF.md` لتنفذه مع وكيل البرمجة الذي تستخدمه، ثم تفحص الناتج. لا تحتاج إلى بناء ماسح أمني جديد أو نسخ مستودعات الأدوات.

| الوكيل | الناتج |
|---|---|
| الباحث | أفكار ومصادر ودرجة يقين، مع تمييز ادعاءات الفوز والجِدّة |
| ناقد البحث | اعتراضات وأسئلة، وإقرار أو طلب تعديل أو رفض |
| محسّن الفكرة | فكرة واحدة، ومتطلبات قابلة للاختبار، ونطاق مستبعد |
| ناقد التحسين | مراجعة الفائدة والجدوى وشروط المسابقة |
| المخطط | ملفات ومهام واعتماديات ومعايير قبول وقرارات لكل أداة |
| ناقد الخطة | مراجعة التغطية وتسلسل التنفيذ والفحوص |
| المصمم | اتجاه بصري ومكونات وحالات وRTL ومصادر وحقوق إعادة استعمال |
| المختبر | سيناريوهات مرتبطة بالمتطلبات، وفجوات وأدلة تنفيذ فعلية |

الاعتراض المتوسط أو الخطير يمنع مرور المرحلة حتى لو كتب الناقد «موافق». يوجد حد للمراجعات واستدعاءات النماذج. كل مرحلة محفوظة بهوية النموذج وبصمات المدخل والمخرج. وجود الرابط في نتائج البحث يثبت مصدره فقط، ولا يثبت صحة كل استنتاج مبني عليه.

للمسابقات المحددة، يطلب النظام الآن تقييمًا استراتيجيًا قبل إعداد خطة البرمجة: ما الذي سيشاهده الحكام، ما أفضل رد محتمل من منافس، كيف يمكن أن تخسر الفكرة، وما تجربة دحضها. القرار `go` أو `clarify` أو `stop`؛ الخياران الأخيران يمنعان إخراج ملف البناء. رابط القواعد الرسمي المقدم في الوصف يجب أن يظهر في البحث الحي. [طريقة استخدام BMAD وgstack وSpec Kit وSuperpowers الأصلية من دون تداخل](docs/strategy-tools.md) تشرح دور كل منها وحدودها.

## التشغيل السريع دون مفتاح

تحتاج Python 3.11 أو أحدث. التخطيط وعرض التقارير يعملان على الأنظمة المعتادة؛ مشغّل الفحوص الخارجية يتطلب Linux أو macOS، أو WSL على Windows. من داخل نسخة المستودع:

```bash
python -m pip install -r requirements.txt
python -m pip install -e . --no-deps
python -m programmed_minds plan --brief examples/brief.json --replay examples/replay.json --out runs/demo
python -m programmed_minds view --run runs/demo
```

افتح `http://127.0.0.1:8765`. هذه تجربة ببيانات مسجلة، **لا تجري بحثًا حيًا ولا تمنح موافقة إطلاق**. استعمل مجلدًا جديدًا لكل تشغيل؛ لا يستبدل التطبيق تقارير سابقة. لإيقاف العرض اضغط Ctrl+C.

### تشغيل مجاني بالمفتاحين فقط

انسخ `examples/free-brief.json` إلى `my-brief.json`، واكتب هدفك وشروط المسابقة وروابط صفحات رسمية حقيقية في `source_urls`، **بما فيها `competition.rules_url` إذا حددته**. يفتح التطبيق حتى 8 صفحات HTTPS عامة من الروابط التي تختارها، ويقدّم مقتطفات منها للباحث والمصمم. الروابط وحدها لا تثبت صحة استنتاجات النماذج، ولا يكتشف النظام مصادر جديدة بهذا المسار. الصفحات التي تتطلب تسجيل دخول أو ملفات PDF غير مدعومة في هذا الوضع.

في PowerShell، بعد تثبيت البرنامج، شغّل:

```powershell
$env:GROQ_API_KEY="الصقي_مفتاح_Groq_هنا"
$env:OPENROUTER_API_KEY="الصقي_مفتاح_OpenRouter_هنا"
python -m programmed_minds plan --brief my-brief.json --config examples/fully-free.json --out runs/free-01
```

لا تكتبي المفتاحين في ملف الوصف أو في Git. الثمانية أدوار تستعمل Qwen على Groq وGLM المجاني على OpenRouter؛ المنتج والناقد في كل مرحلة على مزودين مختلفين. المفتاح المجاني له حدود استخدام وقد تتغير النماذج المتاحة. الإعداد لا يستدعي OpenAI API، لكنه لا يكتب المنتج النهائي: إذا ظهرت `planned` راجعي `runs/free-01/HANDOFF.md` و`approved.json`، ثم أرسليهما لوكيل البرمجة في مستودع المنتج. إذا ظهر `blocked` افتحي `manifest.json` لمعرفة السبب، وأعيدي التشغيل بمجلد جديد.

### نقّاد GLM وQwen المجانيون

يستخدم `examples/free-critics.json` نموذج GLM-5.3-Flash للبحث والخطة وQwen 3.8 27B لتحسين الفكرة عبر واجهتي OpenRouter وGroq. عيّن `OPENROUTER_API_KEY` و`GROQ_API_KEY` و`OPENAI_API_KEY` و`OPENAI_MODEL` في بيئتك، ثم شغّل:

```bash
pminds plan --brief examples/brief.json --config examples/free-critics.json --out runs/free-critics-01
```

أنشئ مفتاح [OpenRouter](https://openrouter.ai/settings/keys) ومفتاح [Groq](https://console.groq.com/keys) من حسابيك. تظل أدوار الباحث والمحسّن والمخطط والمصمم على OpenAI في هذا المثال؛ باحث المشروع ومصممه يحتاجان بحث ويب ومصادر مرصودة. المجانية تخص طلبات النقّاد ضمن حصص المزودين فقط، ولا تعني أن التشغيل الكامل مجاني. حد OpenRouter المجاني حاليًا 50 طلبًا في اليوم؛ افحص حدود حسابك في Groq. لا تفعّل نموذجًا مدفوعًا في ملف الإعداد إن أردت تجنب الرسوم. عند نفاد الحصة أو فشل JSON تتوقف المرحلة دون اعتماد المخرجات.

عدّل `examples/brief.json`: الهدف، الجمهور، القيود، وشروط المسابقة أو رابطها. عيّن `OPENAI_API_KEY` و`OPENAI_MODEL` و`CRITIC_MODEL` في بيئتك، ثم:

```bash
pminds plan --brief examples/brief.json --config examples/models.json --out runs/project-01
```

على PowerShell تستعمل `$env:OPENAI_MODEL="اسم النموذج المتاح لحسابك"`، وعلى Bash تستعمل `export OPENAI_MODEL="اسم النموذج المتاح لحسابك"`، وبنفس الطريقة لبقية المتغيرات. لا تضع المفتاح داخل JSON أو المستودع. ملف `.env.example` توضيحي؛ التطبيق لا يحمّله تلقائيًا.

اختَر نموذجًا يدعم Responses API والمخرجات المنظمة، وبحث الويب للباحث والمصمم. لا يفترض المشروع أسماء نماذج أو أسعارًا ثابتة. إعداد `strict_diversity` يوقف الزوج إذا استعمل النموذج نفسه على endpoint نفسه؛ اختلافهما لا يضمن استقلال الأخطاء. يمكنك تحديد `base_url` و`model` واسم متغير المفتاح لكل دور في `roles`، بشرط دعم endpoint للعمليات المطلوبة. وجود واجهة OpenAI-compatible وحده لا يعني دعم بحث الويب. كلفة API منفصلة عن استخدام الكود؛ لا توجد مفاتيح مضمنة أو ادعاء أن تشغيل النماذج مجاني.

## من الخطة إلى مشروع مفحوص

1. راجع `HANDOFF.md` و`approved.json`. سلّم ملف التنفيذ لوكيل البرمجة داخل مستودع مشروعك، مع Superpowers الأصلي المثبت عندك. هذا التطبيق لا يثبّت مهارات في ChatGPT أو يعدّل إعداداته.
2. ينفّذ وكيل البرمجة المهام واختباراتها، ويختار الأدوات المناسبة حسب التطبيق، ويكتب اختبارات المتطلبات الحقيقية. أمثلة الويب في `integrations/target` نقطة بداية يجب تعديلها؛ ليست دليلًا على فحص تطبيق مجهول.
3. ثبّت الأدوات الأصلية اللازمة، ثم شغّل الفحص على نسخة موثوقة من المشروع. `check` يشغّل كود اختبارات ذلك المشروع، لذلك هو ليس sandbox.

```bash
pminds check --target /absolute/path/to/your/project --config integrations/checks-web-example.json --out /absolute/path/outside-project/check-01
pminds audit --run runs/project-01 --checks /absolute/path/outside-project/check-01/checks.json --config examples/models.json --out runs/audit-01
pminds view --run runs/project-01 --audit runs/audit-01 --checks /absolute/path/outside-project/check-01
```

عدّل إعداد الفحوص بنفسك: `requirement_ids` تربط مجموعة اختبارات حقيقية بالمتطلبات التي تتحقق منها. يحتاج كل متطلب أيضًا `evidence_tool` مناسبًا و`test_id` يطابق اختبارًا منفّذًا بعينه؛ نجاح ماسح أمن لا يثبت أن زر الحفظ يعمل. لا تضف ربطًا قبل أن تكتب تلك الاختبارات. يتطلب Playwright وLighthouse وZAP وk6 اختيار الرابط المملوك ضمن `owned_urls` و`allow_network=true`. حد k6 الافتراضي مستخدم واحد/10 ثوانٍ؛ خطة 10/100/500 مستخدم تُنفّذ تدريجيًا على بيئة اختبار وباختبارات تناسب حملك.

المختبر لا يحوّل `failed` أو `missing` إلى نجاح. اختبارات لم تُنفّذ تظهر `not_run`. ASVS ومراجعة PR وطريقة العمل تحتاج أدلة ومراجعة بشرية إذا جعلتها الخطة إلزامية؛ ما زالت قرارات الإطلاق للبشر. `verified` يعني اجتياز الأدلة الآلية المحددة فقط، وليس شهادة أمن أو جاهزية تجارية.

## الأدوات الأصلية

[تفاصيل التثبيت والربط والتراخيص](docs/tools.md) تشرح Superpowers وPR-Agent/Qodo وASVS وSemgrep وGitleaks وOSV-Scanner وTrivy وZAP وpgTAP وPlaywright وLighthouse CI وSize Limit وk6. كل أداة لها قرار انطباق في الخطة. الفحوص لا تعمل بالاسم فقط: يجب أن تكون الـCLI مثبتة، والاختبارات والإعدادات موجودة.

القاعدة الافتراضية المحلية لـSemgrep صغيرة ومحددة، ولا تمثل تغطية أمنية شاملة؛ استبدلها بمجموعة قواعد مناسبة بعد مراجعة ترخيصها. لا ينسخ المشروع مصدر الأدوات أو قواعدها الخارجية.

## التطوير والتحقق

```bash
python -m unittest discover -s tests -v
```

تشمل الاختبارات التراجع المحدود، والرفض، والمصادر غير المرصودة، وهوية النقاد، وتغطية المتطلبات، والأدوات المفقودة، والأخطاء والمهل، وغياب الاختبارات، ومسارات الملفات، وحقن HTML. بعض اختبارات الأدوات تستعمل بدائل اختبارية؛ اختبار subprocess وHTTP محليان فعليان. تشغيل API الحي والماسحات الأصلية وفحص المتصفح موضح كلٌّ على حدة في [سجل التحقق](docs/verification.md).

التقارير محلية وقد تتضمن وصف مشروعك ومصادره؛ لا تضع أسرارًا في وصف المشروع. سجل فحوص CLI يحذف أنماط أسرار شائعة بأفضل جهد، وهذا لا يضمن كشف كل صيغة. المجلد `runs/` مستبعد من Git.
